GameSpace Lock Fix (Vector / LSPosed module)
Scope: System UI (com.android.systemui) only.
1. Push this folder to a GitHub repo -> Actions tab -> "Build" -> download the GameLockFix-apk artifact.
2. Install the APK, enable it in Vector, tick System UI as scope, restart System UI (or reboot).
3. Play a game, tap the lock in GameSpace, try pulling the status bar down.
Log tag: GameLockFix (check Vector logs).
